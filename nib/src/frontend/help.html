Markdown in Nib

Nib renders Markdown with its own ~300-line parser — no dependencies, and every example below is rendered by that same code, live, so this page can't drift from the editor. Markdown itself is John Gruber's, designed in 2004 with Aaron Swartz: "a text-to-HTML conversion tool for web writers" whose overriding design goal was that a document should be publishable as-is, as plain text.

Prefer to poke at it? Help ▸ Open Example Document opens a copy of everything below as a real, editable file.

The original project page, syntax rules and philosophy: daringfireball.net/projects/markdown — full syntax · basics. Where Gruber's description left room for interpretation, the CommonMark spec pinned it down; Nib follows CommonMark's spirit for the everyday set and GitHub's for tables, task lists and strikethrough.
