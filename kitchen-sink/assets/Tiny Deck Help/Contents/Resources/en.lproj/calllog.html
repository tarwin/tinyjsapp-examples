The call log

Every tiny.* call the deck makes is recorded in the call log, so the deck doubles as its own reference. It opens with what tinyjs.json declared, read back at launch: the version, window size, URL scheme, file types and permissions.

Undock ⧉ moves the log into its own native window. Windows can't read each other's memory, so the log reaches the new window the way everything crosses between windows: through the backend.
