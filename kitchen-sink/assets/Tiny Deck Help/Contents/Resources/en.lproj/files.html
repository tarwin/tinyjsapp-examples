Where the files come from

assets/

Files the operating system reads, each by its name: icon.png (the app icon), Credits.html (the About panel's credits) and this help book. None of them ship as data for the app's own code.

resources/

Data the app's own code reads at runtime. The whole folder ships with the app, and app.paths().resources points at it: the folder itself while developing, the bundled copy once built. The Bundled resources card on the Storage tab reads Tiny Deck's own.
