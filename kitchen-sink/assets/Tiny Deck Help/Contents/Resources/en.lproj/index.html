Tiny Deck Help

Tiny Deck is the tinyjs kitchen sink: one app that shows off the whole tinyjs API as a deck of live demo cards. Play with a control, then read the call you'd write in the call log at the top right.

This page is itself a demo. It's an Apple help book that lives in the project's assets/ folder and is named in tinyjs.json with "macos": { "helpBook": "Tiny Deck Help" }. tinyjs build bundles it, registers it, and indexes it, which is why the search field at the top of the Help menu can find these pages.
